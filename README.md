# 习录 · 每日学习计时

单文件、零依赖的本地学习计时器。打开 `Time.html` 即用，所有记录只留在你自己的浏览器里。

## 特性

- **一段一段地记**：开始 / 暂停 / 继续；结束时可选「结算到上次活跃」「结算到现在」，或直接「丢弃这段」。
- **补录**：漏记了可以一键补一段 —— 最近 1 小时 / 上午 09–12 / 下午 14–18 / 晚上 20–23 / 到现在。
- **三视图**：`今日` 看当天时段分布，`回顾` 看历史，`收工` 做当天结算。
- **目标线**：2h / 4h / 6h / 8h 四档日目标，进度一眼可见。
- **碎碎念与里程碑**：同一天里记下状态和节点，和时长放在一起。
- **事项管理**：科目可增删改，颜色随选。
- **数据自主**：导出备份 JSON / 导入备份 / 清空记录，全程本地完成，不联网。
- **双色族主题**：浅蓝 sky × 浅粉 blossom，三层设计 token（primitive → semantic → component）。

## 快速开始

下载 `Time.html`，双击用浏览器打开即可。无构建、无依赖、无服务端。

## 数据存在哪

- 存储位置：浏览器 `localStorage`
- 键名：`xilu.studyLog`
- 不发送任何网络请求，不采集任何数据。

> ⚠️ `localStorage` 绑定「浏览器 + 打开方式（域名或本地路径）」。换浏览器、换存放路径、清理站点数据，都可能读不到旧记录 —— 请定期用界面里的 **导出备份 JSON** 留一份。
